# Nebula Shop – Galaxy Store

A cosmic-themed online store with an admin panel. Dark galaxy visuals with stars, nebula effects, and a space aesthetic.

## Features

- **Storefront** – Browse products in a grid layout
- **Shopping Cart** – Add, remove, and adjust quantities
- **Admin Panel** – Add, edit, delete products; change admin password
- **Galaxy Theme** – Animated stars, nebula gradients, cosmic colors
- **Persistent Data** – Products and cart saved in browser localStorage

## Quick Start

1. Open `index.html` in a web browser (double-click or drag into browser).
2. Or run a local server (recommended for full functionality):
   ```bash
   npx serve .
   # or
   python -m http.server 8000
   ```
3. Visit the URL shown (e.g. `http://localhost:3000`).
